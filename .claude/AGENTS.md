# Instructions for this repository

This project aims to create a complex **Volleyball Tournament Management System**.

## Plan and TODOs

- Refer to `plan.md` for architecture and conventions. Ask for clarification if necessary.
- Use `PROJECT_TODO.md` for the up-to-date task list. Update it every time you implement a feature.
- If asked for any architecture changes, make sure to update those files accordingly.

## Workflow

- Always lint your changes (`npm run lint`) and fix reported errors and warnings.
- Never run `npm run dev`, assume already running.
